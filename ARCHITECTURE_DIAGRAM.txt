║                          KEY DESIGN DECISIONS                               ║
╚═════════════════════════════════════════════════════════════════════════════╝

1. OFFLINE-FIRST ARCHITECTURE
   Why: Instant response, works without internet, better UX
   How: Save to Room first, sync in background via WorkManager

2. MVVM PATTERN
   Why: Separation of concerns, testability, lifecycle-aware
   How: ViewModel + LiveData + Repository

3. ROOM DATABASE
   Why: Type-safe, compile-time verification, LiveData integration
   How: Entities + DAOs + Database class

4. WORKMANAGER FOR SYNC
   Why: Respects Doze mode, guaranteed execution, retry logic
   How: PeriodicWorkRequest every 15 minutes

5. JWT AUTHENTICATION
   Why: Stateless, scalable, secure
   How: Token in SharedPreferences, added via Interceptor

6. EXACT ALARMS
   Why: Critical for medicine reminders
   How: setExactAndAllowWhileIdle() + BroadcastReceiver

7. COROUTINES
   Why: Simpler than callbacks, structured concurrency
   How: viewModelScope.launch for async operations
